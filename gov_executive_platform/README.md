# المنصة التنفيذية الحكومية (Gov Executive Platform)

منصة تنفيذية حكومية حديثة لإدارة ومتابعة الخطة الاستراتيجية ومشاريع الوزارة على مستوى الرؤساء
التنفيذيين، بأسلوب متابعة مهام يشبه Jira / Trello (لوحات Kanban لكل مشروع)، مبنية بـ Flutter
وواجهة عربية أولى بالكامل (RTL) ومتجاوبة مع مختلف الأجهزة.

## الأدوار والصلاحيات

| الدور | الصلاحيات |
| --- | --- |
| مسؤول نظام (System Admin) | كامل الصلاحيات: إدارة المستخدمين، جميع الإدارات والمشاريع، سجل التدقيق |
| مستخدم تنفيذي (Executive Viewer) | عرض جميع الإدارات والتقارير ومركز القرارات (بدون تعديل)، مع صلاحية اعتماد/رفض القرارات |
| مدير إدارة (Department Manager) | تعديل مشاريع إدارته فقط، إدخال التحديثات اليومية، متابعة لوحة مهام إدارته |
| ضابط مشروع (Project Officer) | تحديث المهام اليومية على لوحة المشروع (الحالة ونسبة الإنجاز) ضمن إدارته |

## أبرز الميزات

- **لوحة قيادة مركزية**: نسبة الإنجاز، التأخير بالأيام، المخاطر، العوائق، القرارات المطلوبة،
  ترتيب الإدارات، ورسوم بيانية تفاعلية (أعمدة ودائرية).
- **صفحات إدارات مستقلة** لكل إدارة مع مؤشراتها ومشاريعها.
- **تحديث يومي مفصل**: إنجازات، مهام منجزة، مخاطر جديدة، عوائق، قرارات مطلوبة، ونسبة تقدم.
- **لوحة مهام لكل مشروع (Kanban)** بأسلوب Jira/Trello: قائمة الانتظار، قيد التنفيذ، قيد المراجعة،
  معلقة، منجزة — مع السحب والإفلات، اسم المنفذ، وقت آخر تحديث، ونسبة الإنجاز.
- **تقارير أسبوعية وشهرية تلقائية** مع ملخص تنفيذي مُولّد، تحليلات، وتعليق نصي يدوي.
- **مركز قرارات تنفيذية** لعرض جميع الطلبات المعلقة مرتبة حسب الأولوية وتأثير التأخير، مع اعتماد/رفض.
- **سجل تدقيق** لكل العمليات، وإدارة مستخدمين للمسؤول.
- تخزين محلي (SharedPreferences) خلف طبقة `AppStore`/`SeedData` قابلة للاستبدال بخدمة API لاحقاً.
