# أصول الهوية الرسمية

## `logo.png` — شعار الوزارة

**مرفوع بالفعل**: شعار وزارة العدل الرسمي (شعار الدولة) بخلفية شفافة، مقتطع
من الشعار الذي زوّده مسؤول النظام. اسم الوزارة والدولة يُكتبان نصاً حياً في
التطبيق (لا داخل الصورة) حتى يظهرا باللون المناسب لكل خلفية.

لاستبداله بنسخة أخرى، ضع الملف هنا بنفس الاسم:

```
logo.png
```

المواصفات المفضّلة:

- صيغة **PNG بخلفية شفافة** (حتى يظهر بشكل سليم فوق الشريط الجانبي الأخضر وفوق
  البطاقات البيضاء معاً).
- عرض لا يقل عن **512 بكسل** (يُصغَّر تلقائياً حسب مكان العرض، لكن الدقة العالية
  تمنع التشوّش على الشاشات الكبيرة وفي التقارير المطبوعة).
- شعار مربّع أو قريب من المربّع يعطي أفضل نتيجة في الشريط الجانبي.

بمجرد وضع الملف هنا وإعادة البناء (`flutter build web --release`)، سيظهر الشعار
تلقائياً في:

1. شاشة تسجيل الدخول.
2. أعلى الشريط الجانبي في كل الصفحات.
3. الشريط العلوي الرسمي.

إن حُذف الملف تعرض المنصة رمزاً رسمياً بديلاً (ميزان العدل) مرسوماً بالكود
بألوان الهوية — فلا تظهر أي صورة مكسورة، ولا يتوقف البناء.

## `frame_border.png` — الإطار الزخرفي الرسمي

بلاطة واحدة (٥٣×١٩٤ بكسل) من الزخرفة الهندسية المعتمدة في وثائق الوزارة،
تُكرَّر رأسياً بلا فواصل. مرسومة بلون واحد مع شفافية، لذا يمكن صبغها بأي لون:

- **تقارير PDF المصدَّرة**: على حافتَي كل صفحة بالأخضر، مطابقة للوثائق الرسمية.
- **شاشة تسجيل الدخول**: على الحافة الخارجية للوحة التعريف بالذهبي المخفّف.

تُستخدم في الكود عبر `OrnamentBorder` (في `lib/widgets/ornament_border.dart`).
